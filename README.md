# serenity-chokepoint-investing

整合 Serenity（白毛女神）供应链瓶颈投资框架到 Hermes Agent 技能体系，同时支持 A股 和 币圈/链上 寻找瓶颈机会。

## 核心思想

> **沿着产业链向上游追溯，找到那个"一旦断货，万亿产业就要地震"的关键节点——那个节点上的小盘股/小市值标的，就是下一个暴击机会。**

这不是基本面投资，也不是技术分析。**这是供应链地缘政治分析。**

### 核心逻辑链

```
AI大爆发 / 公链新技术 / 政策驱动 / 需求爆发
    ↓
上游基础设施/硬件/原材料需求暴增，供应链某些环节产能跟不上
    ↓
瓶颈环节掌握定价权 → 其中小市值标的弹性最大
```

### 霍尔木兹海峡类比

> 霍尔木兹海峡是全球石油的咽喉。一旦封锁，所有人受影响。但如果你在霍尔木兹海峡拥有股份，你就拥有了定价权。
>
> → **哪个环节是当前大赛道的"霍尔木兹"？谁控制它？**

## 适用场景

| 市场 | 适用 | 不适用 |
|------|------|--------|
| **A股** | 科技/AI/半导体/新能源/军工等实体产业链，寻找卡脖子环节小盘股 | 纯题材炒作、无实质产业逻辑、大盘蓝筹 |
| **币圈/链上** | AI公链/Layer1/DeFi/RWA等基础设施赛道，寻找上游关键环节小市值币种 | Meme 纯情绪炒作、无实际技术壁垒 |

## 分析流程（六步法 - A股版）

按照以下六步顺序严格执行，不能跳步：

1. **定位板块/赛道所处周期阶段** — 判断需求爆发/技术跃迁/供给受限
2. **溯源供应链，定位"卡脖子"节点** — 从终端向上游逐层排查，找最容易被卡环节
3. **找出标的，建立"四维信号卡"** — 卡脖子定位、估值水位、资本信号、机构关注度
4. **筛选"真瓶颈"与"伪概念"** — 六条排除规则，严格执行
5. **多空双向确认** — 不做单边多头，对照做多/观望信号
6. **输出结构化分析报告**

## 整合陶博士动量体系

我们已经整合了陶博士的月线反转+口袋支点技术面检查：

1. **Serenity 框架** → 找出真瓶颈标的（基本面+逻辑）
2. **陶博士框架** → 检查技术面/动量/RPS/买点
3. **结论** → 逻辑+技术都满足才是高置信度机会

## 币圈/链上适配

针对公链/加密货币赛道改编：

```
新赛道爆发（AI公链 / 模块化 / Restaking / RWA 等）
    ↓
追溯基础设施上游，哪个环节是所有项目都必须用的？
    ↓
找到目前供给不足/技术壁垒高的瓶颈环节
    ↓
该环节哪个小市值代币占据垄断/主要份额？
```
